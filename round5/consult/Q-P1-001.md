## Questions
1. **Endpoint handling of the interpolant.** The target u contains γ′(t)·P_W z with γ′(t) = σ_b(1 − 2t)/(2√(t(1 − t))),
   which diverges as t → 0 or 1 (ET-Flow Eq. 2–5, E-JOINT-076). The spec draws t ~ U[0, 1]. Should t be drawn from
   U[t_ε, 1 − t_ε] (which t_ε?), should γ′ be clipped, or does the ET-Flow source specify something else?
2. **σ fed to the network in τ-frozen geometry sampling** (M1 evaluation, A6/A6b sampler). Torsions are not noised,
   so should the torsion-clock input be σ_min throughout, or follow TD's geometric schedule in step with t?
3. **"Train only the V2 geometry head"** (§5.2 M1). Is the whole network trained from scratch on the geometry loss only
   (w_τ = 0, τ noise still applied; this is what the 0.3 × 11.7 GPU-h cost assumes)? Or is a frozen pretrained trunk
   (e.g. CTRL_rematch s0) used with only the head trained? Note that a frozen TD trunk has no clock input
   (`lambda_embed_dim = 0`), so t could then enter only the head.
4. **Chirality in V2 training samples.** §2.8 requires rejection for DAgger roll-outs and V3a noise. Should noised V2
   interpolant states x_t that flip a centre also be rejected and resampled, or only counted?
5. **Geometry clock embedding.** Is it acceptable to feed t through TD's λ path with `lambda_embed_dim = 32` (as S4)?
6. **Loss reduction.** Per-molecule sum divided by (3n − 6 − m), then the mean over the molecules in the batch.
   Please confirm.
