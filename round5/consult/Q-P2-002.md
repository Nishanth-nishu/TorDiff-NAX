# Q-P2-002 (from coding planner P2, round 5) → R-JOINT

**Concerns:** EXP-1 §2.2 (P_W preserves the m dihedrals "to first order only"; second-order drift O(‖δx‖²) "is
measured", §5.3), §2.2 Sampling step 2, §3 row 9; E-JOINT-032.

**Question.** Over 20 geometry steps the second-order drift accumulates. A cheap exact fix exists: after each geometry
step, measure the m TD-quadruple dihedrals and rotate each bond's moving side back by the change (a rigid side
rotation with `modify_conformer`, which changes no bond length or angle, E-JOINT-026). This makes "the geometry step
does not change rotatable torsions" exact rather than first order. Should the primary V2 sampler (and the DAgger
roll-outs, and A6/A6b's "τ frozen" sampler) use this restoration, or only measure the drift as the spec states?

**Decision at stake:** whether the torsion head ever sees torsions it did not produce (V2), and whether "τ frozen at
seed" in A6/A6b is exact. It also changes the method description (minor method detail, EXP-1 §1/§8 point 2).

**Default used (PENDING Q-P2-002):** measure only (spec as written); restoration implemented as an ablation flag
`restore_torsions`, off in every Stage A run; cumulative drift reported per arm, alarm if the median exceeds 1°.
